## Suggested first coding milestone after gates

Implement only Phase 03's Hub shell after Phase 00 owner sign-off and Phase 01/02 safety foundations are accepted. It can provide a useful member landing page and clear disabled/coming-soon states without exposing profiles, directory data, activities, registration or messaging prematurely. Use existing authentication and templates; do not add database tables unless the approved design requires them.

## Change control

At each phase, report findings/assumptions, changed files, migration and recovery steps, tests/results, security/privacy considerations, blockers and whether the gate is met. Do not silently advance phases or deploy production changes.
